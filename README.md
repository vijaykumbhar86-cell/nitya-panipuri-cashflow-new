# Nitya Panipuri CashFlow (Fresh rebuild)

This is a simple Android WebView app with no third-party libraries and no microphone bridge. Daily records are saved locally in the app's WebView storage.


## Features
- Cash and UPI totals
- Expenses and estimated profit
- Optional item-count sales entry using menu prices
- Stock/wastage notes and daily notes
- Saved day history
- CSV export
- Logo and red/yellow/green brand palette

## Build
Open the folder in Android Studio and allow Gradle sync. Build > Build APK(s).

Android manifest is at `app/src/main/AndroidManifest.xml`.
HTML app and logo are at `app/src/main/assets/`.
